# GONOVI Beta Versioning

La marca visible del hub GONOVI usa versiones beta manuales para identificar iteraciones de diseño.

## Version actual

- `Beta v3.1`
- Fuente visible: `OFFICIAL_BETA_VERSION` en `src/components/official/OfficialHome.tsx`

## Regla de avance

- Iteraciones menores: `v3.1`, `v3.2`, `v3.3`, `v3.4`, `v3.5`.
- Despues de `v3.5`, pasar a `v4.0`.
- Luego continuar igual: `v4.1` hasta `v4.5`, despues `v5.0`.

## Cuando actualizar

Actualizar la version cuando el cambio sea visible para el usuario: layout, interaccion, animacion, identidad visual o comportamiento del hub.
